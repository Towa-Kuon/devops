# 직접 캡처할 화면

01-pods5.png: replicas 5개가 준비된 kubectl get pods 화면. 교안 60쪽 필수 캡처다.
02-v2.png: v2 제목과 Pod/Host가 보이는 방명록 화면. 비교용 선택 캡처다.
03-rollback.png: 롤백 후 v2가 사라진 제목과 Pod/Host 화면. 비교용 선택 캡처다.

Windows의 Win+Shift+S로 캡처한 뒤 이미지 파일로 저장한다. 실행 파일의 --folder 명령은 이 폴더를 Windows 탐색기로 연다. 화면을 새로 만들어 붙이는 것이 아니라 실제 실행한 창을 캡처한다.
